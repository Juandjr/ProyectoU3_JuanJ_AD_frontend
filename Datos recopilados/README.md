## Dónde se encuentran los datos utilizados

Los datos utilizados para el análisis están en las carpetas:
- `Railway/`
- `Render/`
- `Vercel/`

Ahí se guardan las corridas individuales en formato `*_raw.json` y sus reportes en PDF. Las gráficas y resúmenes finales se derivan de esos archivos.


## Correcciones principales realizadas

De acuerdo con las evidencias consolidadas en esta carpeta, las correcciones principales se enfocaron en:
- ordenar y unificar las corridas por plataforma para facilitar la comparación;
- consolidar resultados crudos y reportes visuales por cada ejecución;
- ajustar la presentación de los reportes comparativos finales;
- generar gráficas de latencia, estabilidad e interrupciones para evidenciar el comportamiento de cada hosting;
- preparar una versión final del documento con iteraciones hasta obtener el reporte de comparación definitivo.
